# ComfyUI CY Nodes 🍌

基于 Gemini API 的 ComfyUI 图像生成和编辑节点，支持文生图、图片编辑、批量生成等功能。

![节点预览](https://img.shields.io/badge/ComfyUI-Custom_Nodes-blue)
![版本](https://img.shields.io/badge/version-1.0.0-green)

---

## ✨ 功能特点

- 🎨 **文生图** - 通过文字描述生成高质量图片
- 🖼️ **图片编辑** - 对现有图片进行 AI 编辑和修改（支持最多8张参考图）
- 🔄 **批量生成** - 支持同时生成多张图片（最多10张），提高效率
- 📝 **批量提示词** - 按行拆分提示词，每行独立生成不同图片
- 🔑 **自动创建令牌** - 一键生成临时 API Key，保护主 Key 安全
- 💾 **API Key 自动保存** - 首次输入后自动保存，无需重复填写
- 📐 **多种宽高比** - 支持 1:1、4:3、3:4、16:9、9:16、2:3、3:2、21:9、4:5、5:4
- 🎯 **多种尺寸** - 支持 1K、2K、4K 等多种分辨率
- 🎲 **随机种子** - 支持设置种子复现结果，或自动随机

---

## 📦 包含节点

| 节点名称 | 类名 | 功能说明 |
|---------|------|---------|
| **CY文生图** | `CYTextToImage` | 文字描述 → 生成图片（支持批量生成，最多10张） |
| **CY图片编辑** | `CYImageEdit` | 输入图片 + 描述 → 编辑后的图片（支持8输入5输出） |
| **初阳图像保存** | `CYOptionalSave` | 保存生成的图片到本地（支持跳过空输入） |

## 🚀 安装方法

### 方式一：通过 ComfyUI Manager（推荐）

1. 打开 ComfyUI Manager
2. 搜索 `CY Nodes` 或 `ComfyUI_CY_Nodes`
3. 点击 **Install** 安装
4. 重启 ComfyUI

### 方式二：Git 克隆

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/XY121718/ComfyUI_CY_Nodes.git
```

### 方式三：下载 ZIP

1. 点击 GitHub 页面的 **Code → Download ZIP**
2. 解压到 `ComfyUI/custom_nodes/ComfyUI_CY_Nodes`
3. 重启 ComfyUI

> ⚠️ **无需安装额外依赖**，所有库都是 ComfyUI 自带的！

## 📖 使用教程

### 🔑 第一步：获取 API Key

你需要一个支持 Gemini API 的中转服务 Key：

| 中转服务 | 网址 | 特点 |
|---------|------|------|
| **星核AI** | https://api.xheai.cc | ✅ 支持自动创建令牌 |
| **aicy168** | https://ai.aicy168.top | 备用中转 |

---

### 🎨 第二步：使用 CY文生图（基础用法）

1. 在节点面板搜索 `CY文生图` 并添加到画布
2. **中转网址**：选择你的 API 服务商
   - `https://api.xheai.cc` - 星核AI（推荐，支持自动创建令牌）
   - `https://ai.aicy168.top` - 备用中转
3. **Key1**（必填）：填入你的 API Key
4. **提示词**：描述你想生成的图片，例如：
   ```
   一只可爱的橘猫，坐在窗台上，阳光照射，高清摄影
   ```
5. **模型**：选择使用的 AI 模型
   - `gemini-3-pro-image-preview` - Gemini 官方模型（推荐）
   - `gemini-3.1-flash-image-preview` - Gemini Flash 模型（速度快）
   - `nano-banana` - 优化模型
   - `nano-banana-2` - 优化模型 v2
   - `nano-banana-2-2k` - 2K 分辨率优化
   - `nano-banana-2-4k` - 4K 分辨率优化
6. **默认宽高比**：选择图片比例（1:1、4:3、16:9 等）
7. **图像尺寸**：选择分辨率（1K、2K、4K）
8. **生成张数**：设置同时生成的图片数量（1-10张）
9. 连接输出到 **预览图片** 或 **初阳图像保存** 节点
10. 点击 **Queue Prompt** 开始生成

---

### 🚀 第三步：批量生成（高级用法）

#### 方式一：同时生成多张（生成张数）

**适用场景**：使用相同提示词生成多张不同的图片

1. 设置 **生成张数** 为 2-10
2. 系统会并行生成多张图片，速度更快
3. 所有图片使用相同的提示词，但结果会有差异

**示例**：
```
提示词：一只可爱的橘猫
生成张数：5
结果：生成5张不同姿态的橘猫图片
```

> 💡 **优势**：并发请求，速度快，适合需要多个候选结果的场景
>
> ⚠️ **注意**：生成张数越大，消耗的 API 配额越多

#### 方式二：不同提示词生成不同图片（按行拆分）

**适用场景**：需要生成多张完全不同内容的图片

1. 开启 **按行拆分提示词**（批量提示词）
2. 在提示词框中，用**两次回车**（空行）分隔不同的描述：
   ```
   一只可爱的橘猫

   一只黑色的小狗

   一只白色的兔子
   ```
3. 每行提示词会独立生成一张图片
4. 最多支持 5 段提示词

**示例**：
```
提示词：
一只橘猫在窗台上

一只小狗在草地上

一只兔子在花园里

结果：生成3张完全不同的图片
```

> 💡 **优势**：一次运行生成多种不同内容，提高工作效率
>
> ⚠️ **注意**：
> - 生成张数 > 1 时，不能同时开启按行拆分
> - 必须用两次回车（空行）分隔，单次回车无效

---

### 🖼️ 第四步：使用 CY图片编辑

CY图片编辑 可以对现有图片进行 AI 编辑，支持最多 **8张输入图片** 和 **5张输出图片**。

#### 基础用法：单图编辑

**适用场景**：对单张图片进行修改、优化或风格转换

1. 在节点面板搜索 `CY图片编辑` 并添加到画布
2. 填写 **Key1**（必填）
3. 将要编辑的图片连接到 **输入1**
4. 在 **提示词** 中描述你想要的修改，例如：
   ```
   把背景改成海边，添加夕阳效果
   ```
5. 运行即可获得编辑后的图片（输出1-5 会生成不同的编辑结果）

**示例场景**：
- 更换背景：`将背景替换为森林场景`
- 添加元素：`在图片中添加一只蝴蝶`
- 风格转换：`将照片转换为油画风格`
- 色调调整：`调整为暖色调，增加阳光感`

#### 高级用法：多图合成/参考编辑 🔥

**核心功能**：可以输入多张图片作为参考，AI 会综合所有输入图片的内容进行编辑！

**使用场景举例：**

1. **风格迁移**：输入1放原图，输入2放风格参考图
   ```
   提示词：将图1的内容用图2的风格重新绘制
   ```

2. **换脸/换装**：输入1放人物照片，输入2放目标服装
   ```
   提示词：把图1中的人物穿上图2中的衣服
   ```

3. **场景合成**：输入1放人物，输入2放背景
   ```
   提示词：把图1中的人物放到图2的场景中
   ```

4. **多图融合**：输入多张图片，生成综合效果
   ```
   提示词：融合所有输入图片的元素，创作一张新图
   ```

5. **色彩参考**：输入1放原图，输入2放色彩参考
   ```
   提示词：参考图2的色调，将图1重新上色
   ```

#### 多图编辑操作步骤：

1. 将 **主图片** 连接到 **输入1**
2. 将 **参考图片** 连接到 **输入2、输入3...** （最多8张）
3. 在提示词中说明如何使用这些图片，例如：
   ```
   参考图2的色调，将图1重新上色
   ```
4. 运行后，**输出1-5** 会生成不同的编辑结果

#### 图片编辑特有功能：

| 参数 | 说明 |
|------|------|
| **输入1-8** | 可连接最多8张参考图片，AI 会综合分析所有图片 |
| **输出1-5** | 最多输出5张不同的编辑结果，提供多个候选方案 |
| **匹配参考尺寸** | 开启后，输出图片保持输入1的尺寸（关闭则使用默认宽高比） |
| **按行拆分提示词** | 多行提示词分别对应不同的编辑任务（每行对应一个输出） |

#### 批量编辑模式：

开启 **按行拆分提示词** 后，可以对不同输入执行不同的编辑任务：

```
提示词：
将背景改成海边

添加夕阳效果

转换为油画风格
```

- 第1行提示词 → 使用输入1 → 输出到输出1
- 第2行提示词 → 使用输入2 → 输出到输出2
- 第3行提示词 → 使用输入3 → 输出到输出3

> 💡 **提示**：如果只有输入1，所有提示词都会应用到输入1上


---

### 💾 第六步：保存图片

使用 **初阳图像保存** 节点保存生成的图片。

#### 基础用法：

1. 在节点面板搜索 `初阳图像保存` 并添加到画布
2. 将 CY文生图 或 CY图片编辑 的输出连接到 **images** 输入
3. 设置 **filename_prefix**（文件名前缀），例如：`my_image`
4. 运行后，图片会自动保存到 ComfyUI 的输出目录

#### 特点：

- **支持批量保存**：自动保存所有生成的图片
- **自动编号**：文件名格式为 `前缀_00001_.png`
- **保存元数据**：自动保存工作流信息到 PNG 元数据
- **容错处理**：如果输入为空（None），会自动跳过保存

#### 输出目录：

默认保存到 `ComfyUI/output/` 目录下

### ✅ 第七步：自动创建令牌（推荐！）

如果你使用 **api.xheai.cc** 中转服务，强烈建议使用自动创建令牌功能：

#### 操作步骤：

1. **中转网址** 选择 `https://api.xheai.cc`
2. 在 **总Key（创建令牌用）** 中填入你的主 Key
3. 点击 **✅ 点击自动创建令牌** 按钮
4. 系统会自动生成一个临时 Key 并填入 Key1

#### 为什么要用这个功能？

| 优势 | 说明 |
|------|------|
| 🔒 **更安全** | 临时 Key 用完即弃，不怕泄露主 Key |
| 💰 **更可控** | 可以限制临时 Key 的配额和使用范围 |
| 🔄 **更方便** | 一键生成，无需手动复制粘贴 |
| 🛡️ **保护主Key** | 主 Key 保存在单独的配置文件中，不会暴露 |

> ⚠️ **注意**：此功能仅支持 api.xheai.cc 中转服务

## ❓ 常见问题

### 配置相关

**Q: 提示 "请在总Key随便填入一个有效Key"**
> A: 点击自动创建令牌前，需要先在"总Key"输入框填入你的主 API Key。

**Q: API Key 保存在哪里？**
> A: 保存在插件目录下的 `config.ini` 和 `master_key.ini` 文件中，这些文件已被 `.gitignore` 忽略。

**Q: 如何更换 API Key？**
> A: 直接在节点的 Key1 输入框中输入新的 Key，系统会自动保存并覆盖旧的 Key。

### 生成相关

**Q: 生成失败，提示 401 错误**
> A: API Key 无效或已过期，请检查 Key1 是否正确填写，或尝试重新创建令牌。

**Q: 生成张数设置大于1后报错**
> A: 确保没有同时开启"按行拆分提示词"，这两个功能不能同时使用。

**Q: 如何复现相同的图片？**
> A: 记录生成时的种子值，下次使用相同的种子、提示词和参数即可复现。

**Q: 生成的图片尺寸不对**
> A: 检查"默认宽高比"和"图像尺寸"设置，或在图片编辑中开启"匹配参考尺寸"。

**Q: 批量提示词不生效**
> A: 确保使用**两次回车**（空行）分隔提示词，单次回车无效。

### 编辑相关

**Q: 图片编辑效果不理想**
> A: 尝试以下方法：
> - 使用更详细的提示词描述
> - 提供更多参考图片
> - 调整模型选择
> - 多次生成选择最佳结果

**Q: 多图编辑时如何指定使用哪些图片？**
> A: 在提示词中明确说明，例如："参考图2的风格，将图1重新绘制"。

**Q: 输出图片数量不够**
> A: CY图片编辑最多输出5张，如需更多结果，可以多次运行节点。

### 性能相关

**Q: 生成速度很慢**
> A:
> - 降低图像尺寸（4K → 2K → 1K）
> - 使用更快的模型（如 gemini-3.1-flash-image-preview）
> - 减少生成张数
> - 检查网络连接

**Q: 如何提高生成速度？**
> A: 使用"生成张数"功能并发生成多张图片，比逐个生成快得多。

### 更新相关

**Q: 如何更新节点？**
> A:
> - 通过 ComfyUI Manager 点击 Update
> - 或在命令行执行 `git pull`

**Q: 更新后节点不显示**
> A: 重启 ComfyUI，或检查控制台是否有错误信息。

## 💡 最佳实践

### 提示词编写技巧

1. **具体明确**：描述越详细，结果越准确
   ```
   ❌ 一只猫
   ✅ 一只橘色的短毛猫，坐在木质窗台上，阳光从左侧照射，高清摄影
   ```

2. **风格描述**：添加艺术风格关键词
   ```
   油画风格、水彩画、赛博朋克、写实摄影、动漫风格、极简主义
   ```

3. **质量提升**：添加质量相关词汇
   ```
   高清、4K、专业摄影、精细细节、电影级光影、大师作品
   ```

4. **构图指导**：说明构图和视角
   ```
   正面视角、俯视图、特写镜头、全景、黄金分割构图
   ```

### 工作流推荐

#### 基础文生图工作流
```
CY文生图 → 预览图片
         → 初阳图像保存
```

#### 批量生成工作流
```
CY文生图（生成张数=5） → 预览图片
                      → 初阳图像保存
```

#### 图片编辑工作流
```
加载图片 → CY图片编辑 → 预览图片
                     → 初阳图像保存
```

#### 多图合成工作流
```
加载图片1 ─┐
加载图片2 ─┼→ CY图片编辑 → 预览图片
加载图片3 ─┘              → 初阳图像保存
```

### 性能优化建议

1. **合理设置分辨率**
   - 测试阶段：使用 1K
   - 正式生成：使用 2K
   - 高质量输出：使用 4K

2. **并发生成**
   - 需要多个候选结果时，使用"生成张数"功能
   - 比逐个生成快 3-5 倍

3. **批量提示词**
   - 需要生成不同内容时，使用"按行拆分提示词"
   - 一次运行完成多个任务

4. **图片压缩**
   - 图片编辑会自动压缩超过 1536px 的输入图片
   - 无需手动调整输入图片大小
