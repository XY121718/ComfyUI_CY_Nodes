# 🍌 Banana Pro 节点说明书

欢迎使用 **Banana Pro**自定义节点！它是初阳为星核AI（ai.aicy168.top）专门打造的香蕉2Pro超级节点。

## ✨ 功能亮点
- 🔑 **多 Key 并发调度**：支持最多 5 把 API Key，并行请求 `Nano Banana 2` 服务；可为每把 Key 选择独立宽高比，或继承全局默认值。
- 🧩 **提示词/参考图映射**：启用“按行拆分提示词”后，提示词与参考图会一一对应；每个通道只处理自己的提示词和图片，输出到 `输出图1~输出图5`。
- 🖼️ **引用图编辑**：最多接受 8 张参考图；内置尺寸限制、PNG/JPEG 自动转换、匹配参考尺寸等；无图时等同于纯文生图。
- 💾 **Key 自动保存**：Key1~Key5 会写入 `config.ini` 并在下次加载时自动填充，避免重复输入。
- 🧠 **智能缓存**：节点会缓存最近一次的输出，即使单独执行某个保存节点也能获得上次生成的图片，避免 `None` 造成报错。
- 🛡️ **错误提示与重试**：集成请求重试、任务轮询、中文错误提示；能检测 Key 和宽高比配置是否缺失，并提示解决方法。
- 🧭 **友好的中文 UI**：所有控件都使用中文名称并辅以 emoji 说明，让节点更易读、更易用。

## ⚙️ 安装与使用
1. 将 `ComfyUI_CY_Nodes` 文件夹放入 `ComfyUI/custom_nodes/`。
2. 重启 ComfyUI 或在菜单选择 “Reload Custom Nodes”。
3. 在工作流中添加 **Banana Pro** 节点（分类：初阳），输入提示词及 Key 即可使用。

## 📌 使用建议
- 若需要多图多提示词，请启用 “✂️ 按行拆分提示词”，并确保提示词/参考图数量一致。
- 建议开启 “📏 匹配参考尺寸” 以保持编辑图片的分辨率一致。
- 当某个通道 API 失败时，可重新排队执行，节点会自动重试或输出上一次成功的结果。
